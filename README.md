# MarketCrash

A Mac app that watches the S&P 500 and shows how stressed the market is on three gauges from 0 to 100. It only watches. It never trades or connects to a brokerage.

> **Not financial advice.** MarketCrash is for information only and can't predict crashes. Read the [disclaimer](#disclaimer) before you use it.

**[Download MarketCrash for Mac](https://github.com/sheepyyyyy/MarketCrash/releases/latest/download/MarketCrash.dmg)**

You need a Mac with Apple Silicon (M1 or newer) running macOS 14 Sonoma or later.

## Installing

1. Open the downloaded MarketCrash file and drag MarketCrash onto the Applications folder.
2. Open your Applications folder and double-click MarketCrash.
3. Your Mac will say it can't check MarketCrash for malicious software. That's because it isn't registered with Apple. Click Done.
4. Open System Settings, go to Privacy & Security, scroll down to the message about MarketCrash and click Open Anyway. Enter your password if it asks.
5. When MarketCrash asks to send notifications, click Allow so it can tell you when a gauge rises.

Steps 3 and 4 are only needed the first time.

Closing the window keeps MarketCrash running in the menu bar next to the clock. Click the number there to open it again, or choose Quit MarketCrash to stop it.
